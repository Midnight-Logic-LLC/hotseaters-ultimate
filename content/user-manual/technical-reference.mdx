# Technical Reference

Components, pages, utilities, and code structure.

## Page Components

### Public / Unauthenticated Pages

- **Landing** — Marketing landing page with features and CTA.
- **Onboarding** — First-time setup: tenant creation, Google Calendar connection.
- **AcceptInvite** — Team invitation acceptance with auth redirect handling.
- **ReferralLanding** — Public referral landing page for companies invited to join HotSeaters / HotSeatHub.
- **SignDocument** — Public e-signature interface via DocuSeal embed.
- **ViewDocument** — Public document viewing without signature requirement.
- **HSHDirectory** — Public browsable directory of marketplace tenants and consultants.
- **PrivacyPolicy / TermsOfService** — Legal pages (public).

### Dashboard & Core

- **Dashboard** — Main dashboard with KPIs, revenue charts, quick actions. See [Dashboard](/user-manual/dashboard).
- **SalesHub** — Sales-focused view with deals pipeline, revenue projections, client insights. See [Sales Hub](/user-manual/sales-hub).

### Sales & Client Management

- **Deals** — Sales pipeline (renders `PipelinePageContent` with `mode='deals'`). See [Deals](/user-manual/deals).
- **Clients** — Client CRM with attorneys, addresses, service overrides, contact transfer. See [Clients](/user-manual/clients).

### Operations Management

- **Trials** — Active trials (renders `PipelinePageContent` with `mode='trials'`). See [Trials](/user-manual/trials).
- **Schedule** — Timeline view with drag-drop, grouped by trial or consultant, revenue chart. See [Schedule](/user-manual/schedule).

### Time & Financial Management

- **TimeTracking** — Time clock, manual entry, travel time, spreadsheet, expense management with receipt/mileage wizard. See [Time Tracking](/user-manual/time-tracking).
- **Approvals** — Dedicated approval hub for time entries and expenses with bulk actions, status filtering, composable group-by toggles. See [Approvals](/user-manual/approvals).
- **Billing** — Single-view 4-column kanban (Approve Time, Approve Expenses, Create Invoices, Send Invoices). See [Billing](/user-manual/billing).
- **Collections** — Standalone 3-column kanban (Open / Overdue / Paid) with invoice preview and payment tracking. See [Collections](/user-manual/collections).

### HotSeatHub Marketplace

- **PotentialGigs** — Browse marketplace requests with kanban/list/card views, submit responses. See [Potential Gigs](/user-manual/potential-gigs).
- **HelpWanted** — Manage posted requests, review/accept/negotiate responses. See [Help Wanted](/user-manual/help-wanted).
- **HSHDirectory** — Public directory of marketplace tenants and consultants with profiles, ratings, skills.
- **HotSeatHubMarketing** — Marketing page shown to tenants without HSH subscription.

### Team & Settings

- **Consultants** — Team roster with card/list views, invitations, referral invitations, roles, tiers, qualifications. See [Consultants](/user-manual/consultants).
- **Settings** — Multi-tab config: General, Services, Pipeline, Documents, Marketplace, Theme, Tiers, Subscription, Time Tracking, Admin. See [Settings](/user-manual/settings).

### Documentation

## Custom Hooks

- **useCurrentUserAndInfo** — Fetches Supabase user + `user_profiles` on mount via TanStack Query. Query key: `'currentUserAndInfo'`.
- **useNotifications** — Subscribes to Supabase Realtime for unread notifications with count.
- **useAcceptHSHResponse** — Reusable hook for accepting marketplace responses (creates assignment, generates PDF, syncs calendar).
- **useCreateHSHRequest** — Reusable hook for creating marketplace requests.
- **useHSHNegotiation** — Hook for counter-offer and decline actions on HSH responses.
- **useTrialDateUpdate** — Handles trial/service date updates with notifications and calendar sync.
- **useContinuedMutation** — Hook for trial continuation workflow.
- **useReceiptProcessor** — Hook for receipt upload, OCR extraction, and image deskew pipeline (see [External Integrations](/user-manual/external-integrations)).
- **useSubUserExpiry** — Tracks 14-day `pg_cron` expiry window for email + Google OAuth sub-user signups.

## Data Fetching Patterns

All data access goes through TanStack Query against Supabase (via the typed client) or Supabase Edge Functions / Next.js Route Handlers. Scheduled work runs via `pg_cron` — there is no Vercel Cron and no `vercel.json`.

### Standard Query Pattern

```ts
const { data: trials = [], isLoading } = useQuery({
  queryKey: ['trials', tenantId],
  queryFn: async () => {
    const { data, error } = await supabase
      .from('trials')
      .select('*')
      .eq('tenant_id', tenantId);
    if (error) throw error;
    return data;
  },
  enabled: !!tenantId,
});
```

### Mutation with Optimistic Update

```ts
const mutation = useMutation({
  mutationFn: async (data: Partial<Trial>) => {
    const { error } = await supabase.from('trials').update(data).eq('id', id);
    if (error) throw error;
  },
  onMutate: async (data) => {
    await queryClient.cancelQueries({ queryKey: ['trials'] });
    const previous = queryClient.getQueryData(['trials', tenantId]);
    queryClient.setQueryData(['trials', tenantId], (old: Trial[] = []) =>
      old.map((t) => (t.id === id ? { ...t, ...data } : t)),
    );
    return { previous };
  },
  onError: (_err, _data, context) => {
    queryClient.setQueryData(['trials', tenantId], context?.previous);
  },
  onSuccess: () => queryClient.invalidateQueries({ queryKey: ['trials'] }),
});
```

### Edge Function Invocation

```ts
const { data, error } = await supabase.functions.invoke('functionName', {
  body: { param: 'value' },
});
if (error) throw error;
```

Route Handlers under `app/api/*/route.ts` follow the same shape for work that belongs to the Next.js runtime rather than Supabase Edge.

## Styling Conventions & Theme System

HotSeaters v1 ships a single theme. Dual-theme (dark-mode) support is deferred — see the theme stance note in change-510.

### CSS Variables

All styling uses CSS variables from `generateThemeCSS`:

```text
--theme-brand-primary, --theme-brand-secondary, --theme-accent-cool, --theme-accent-warm
--theme-stone-50 through --theme-stone-900
--theme-text-page-title, --theme-text-card-title, --theme-text-body, --theme-text-label, --theme-text-caption
--theme-page-padding, --theme-card-padding, --theme-card-gap, --theme-element-gap
--theme-card-radius, --theme-button-radius, --theme-input-radius
--theme-card-shadow, --theme-button-shadow
--theme-font-body, --theme-font-sidebar, --theme-font-brand-title, --theme-font-brand-subtitle
--theme-success, --theme-warning, --theme-danger, --theme-info
--theme-sidebar-bg, --theme-page-bg, --theme-card-bg, --theme-card-header-bg, --theme-input-bg
--theme-hsh-background (purple tint for HSH items)
```

### Usage Convention

Use inline `style={{ color: 'var(--theme-stone-600)' }}` for themed values. Tailwind is used for layout (flex, grid, spacing). Theme variables cover all colors, fonts, borders, and shadows.
